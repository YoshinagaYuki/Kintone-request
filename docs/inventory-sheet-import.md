# 2026-10-23 旧在庫シート取り込み

対象: 既存在庫スプレッドシートのオールマイト8タブ、元の手入力範囲（249行目まで）。自動転記範囲は取り込まない。

- 管理番号一致12セル → 既存8申請へ紐づけ。申請の期間・商品を正として在庫を二重計上しない。
- 番号なし23セル → 元の担当者表記・店舗名・結合セルの日付範囲を保持して表示。
- 番号なしの返却期間2セル → 独立した利用不可期間として計上。
- システムに該当管理番号がない91セル → ユーザー指定によりスキップ。
- 月を跨ぐ入力は元の月別セルを保存。件数は案件数ではなく入力セル数。
- 「要確認」は他の担当者へ勝手に置換しない。
- 元シートの入力を変更せず、kintoneへの書き込みは行わない。

`inventory_sheet_entries` は元タブ・セル・原文・期間と紐づけを保存。クライアントは有効な管理者のみ閲覧でき、直接変更できない。サービス側の取り込みは監査ログに記録。同じsource_keyの再投入は重複挿入しない。

`extract-sheet.py <xlsx> <DBの最小スナップショットJSON> <出力JSON>` は読み取り専用の抽出ツール。2026年10月から翌年1月という元シートの期間を前提とする。別期間への再利用は年を再確認する。データ・認証情報はGitへ含めない。

今後のシート上での追記は自動再取り込みしない（一度の移行）。現在の自動転記はIMPORTDATAで、約1時間ごとに更新確認。リアルタイムの書き込み接続は別途必要。
