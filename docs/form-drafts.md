# 入力途中の自動保存（2026-11-26）

新規申請・申請編集・在庫確保・予定編集・仮押さえから本登録・コピー/延長を対象に、ブラウザの下書きを自動保存する。

- 同じ端末・ブラウザで7日間。管理者のアカウント、案件、フォームを分けて保存。
- 画面の戻る、閉じる、リロード後、同じ入力画面を開くと復元。
- 手動の日付、連絡先、商品行と数量、社内本登録のチェック、費用も保存。
- 登録成功時に削除。入力エラー・通信失敗では保持。破棄には確認を表示。
- 元の申請・予定が別途更新された場合、古い編集を黙って復元しない。更新競合のサーバーチェックも維持。
- 下書きの復元では送信・承認・在庫更新・kintone書き込みを行わない。
- ブラウザ保存が利用できない場合は画面に警告。他端末への同期は行わない。

## 確認

在庫関連テスト336件成功、production build成功。
ローカルの実際の両事業フォームで、フォームの再表示、別ページから戻る、リロード、事業間の分離、手動集荷日、社内本登録チェック、商品行追加と数量、SNS選択、下書き破棄を確認。テスト専用画面は削除。実申請やメールの送信なし。
