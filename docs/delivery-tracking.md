# 納品予定の伝票表示（2026-11-27）

週間の納品予定を開いた時と「最新情報を取得」を押した時、kintoneの配送会社・配送追跡番号・配送追跡リンクを取得して案件カードに表示。

- 管理表側の日程を使って対象の管理番号を抽出。倉庫の配送管理（App11、既存環境設定を利用）の情報を優先。
- 配送管理にレコードがない過去案件は、その事業の手配管理（App10またはApp49）を参照。異なるレコードの業者と番号を混ぜない。
- 読取専用。管理表・kintoneの日程、在庫、申請内容、配送完了の記録は更新しない。
- 管理者認証と事業権限を確認し、対象週の管理番号だけ検索。追跡リンクはHTTPSのみ。
- 同一管理番号が複数の場合は誤表示を避けて確認メッセージを表示。未入力、取得中、取得失敗も区別。
- 更新の常時プッシュや定期同期ではなく、表示時の最新参照。ブラウザから認証情報を渡さず、既存のサーバー側API認証を使う。
