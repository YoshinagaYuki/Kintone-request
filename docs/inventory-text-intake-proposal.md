# 営業メッセージから仮押さえ — 可否検討（2026-10-29）

実現可能。今回の依頼は可否検討であり、AI呼び出し・課金設定・チャットへの投稿や読み取り権限の追加は行っていない。

## 推奨する順序
1. 認証済みサイト内に文章貼り付け欄を作る。
2. 実際の表記ゆれ・複数案件・日付表現で抽出精度を評価する。
3. 同じ抽出処理をGoogle ChatまたはLINE WORKSに接続する。Google Chatはまずメンション方式、全投稿の監視は別途必要性・権限を確認する。

## 認識と確認
- 担当者、店舗、日程、レンタル品・台数、商品・個数を別々に抽出する。
- 最新のマスタ候補だけを提示し、新しい名前・曖昧な略称は候補選択を求める。
- 元文章中の根拠を表示する。AIの自己申告の確信度だけで保存可否を決めない。
- 日付は投稿時刻/JSTを基準に解釈するが、年・月・利用/納品の区別が曖昧なら確認する。
- 利用開始/終了から前日納品・翌日集荷、逆方向の連動も既存ルールを使う。
- 「スクイーズ300個」と「スクイーズLABを1セット」は別データ。
- プレビューで確認後、既存の在庫確保API・空き番号割当・4日間隔判定・競合ロックを使用する。
- 原文・抽出結果・補正・操作者・保存結果を追跡する。チャット再配信/再クリックで重複作成しない。
- 文章中の指示はデータとして扱い、権限・マスタ・在庫ルールを変更させない。

## 費用の例とデータ
Gemini 2.5 Flash-Lite標準: 入力100万トークン0.10米ドル、出力100万トークン0.40米ドル（参照時点）。入力3,000・出力500トークンなら1,000件で約0.50米ドル。仮のトークン量に基づく計算で、再試行・思考トークン・他の基盤費用・税は別。モデルは実文で品質を確認して選定する。
業務データは課金設定済みAPIを想定する。課金サービスのプロンプト・応答は製品改善に使用されないが、安全性確認等の限定的ログはあり得る。仮押さえに不要な電話・メール・詳細住所は送信対象から除く。Workspace契約とAPIの課金/設定は区別する。
