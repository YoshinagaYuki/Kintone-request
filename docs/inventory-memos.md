# 在庫管理表の社内メモ

予定の編集画面の上部でメール件名・受信日・要点などを2000文字まで記録する。「メモだけ保存」は日付・番号・申請状態・外部システムを変更しない。同じ案件の商品は共有する。空欄で保存すると消せる。

管理表上部の検索で、メモ・店舗・担当者・管理番号・商品を、現在の事業内の商品と表示期間をまたいで検索する。スペース区切りは全語一致。全角半角と英字大小文字を吸収する。結果から編集画面を開ける。在庫の空き判定のため、管理表本体の予定は検索で除外しない。

仮押さえ・本登録済み（申請経由／手動）・取り込み済みの予定に対応。確定元や仮押さえ紐付けから本登録へメモを引き継ぐ。本登録後の明示的な空欄保存は引継ぎ元のメモを再表示しない。社内専用で企業別URLやCSVには出さない。

保存は有効な管理者のみ。既存の在庫編集JSONへメモのキーだけを原子的にマージする。更新競合は在庫時計で防ぎ、監査記録を残す。RPCはservice_roleのみ実行可、invoker、空search_path。保存・競合検出はロールバックする架空キーで検証した。
