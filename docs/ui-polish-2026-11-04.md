## References and applied lessons
1. Linear 2026 refresh: https://linear.app/now/behind-the-latest-design-refresh — consistent command placement, calm navigation, reduce gratuitous borders and visual competition. Apply softer inactive chrome, focused selected states, no decorative icons everywhere.
2. Atlassian elevation: https://atlassian.design/foundations/elevation/ — consistent surfaces and restrained elevation, strongest shadow for overlays. Apply shared border/radius/shadow tokens, subtle card depth, clear modal layers.
3. Shopify purposeful semantic color: https://polaris-site-prod-kit.shopify.prod.shopifyapps.com/design/colors — color tied to meaning. Preserve green confirmed / amber hold / blue pending / red errors. Reference using-color page returned502; do not claim fully reviewed it.
