# 企業別レンタル閲覧ページ

管理画面の「企業別URL」から企業を選び、当月のプレビューを確認してURLを発行する。URLを持つ人は、その企業の確定済み案件を閲覧できる。停止後の新規取得は拒否され、再発行すると旧URLは無効になる。既に保存・ダウンロードされた情報は取り消せない。

株式会社の前後・（株）・全半角・空白・Unity/ユニティを統一する。曖昧な類似名や有限会社、支店名は自動統合しない。承認時の企業名編集は現在の「企業名」と旧「取次店名」の両方に反映する。

当月に利用期間が重なる案件を、PCは表、スマホはカードで表示する。50件ずつ表示し、検索・事業フィルターとCSVは全対象件数に適用する。料金は申請単位で一度だけ計上し、過去の未登録金額を0円とみなさない。両料金が登録済みの案件のみ集計する。期間をまたぐ料金を月割り・日割りしない。

## アクセス制御

- URLは32バイトのランダム値。照合用SHA256とAES-GCM暗号文を保存する。
- URL管理テーブルと操作関数はservice_roleのみアクセス可能。管理APIと関数の双方で有効な管理者を確認する。
- 企業キーでDB絞り込み後、表示モデルでも企業を再確認する。
- 公開モデルは項目を限定し、申請者の連絡先・内部備考・生データを含めない。
- 公開ページ・CSVはキャッシュ禁止、参照元送信禁止。CSVの式として評価される文字列を無害化する。
- 暗号鍵はサービスキー由来。サービスキー変更後に管理画面でURLを復号できない場合は再発行する。
