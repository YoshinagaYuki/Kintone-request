# 仮押さえの進捗とキャンセル確認

登録区分で「仮押さえ」「配送情報待ち」「本登録」をまとめて管理する。別の入力状況欄は設けず、「変更を保存」で反映する。仮押さえは黄色、配送情報待ちはオレンジ、本登録は緑で管理表に表示する。

- 仮押さえ一覧と編集画面に進捗を表示。変更は同じ案件の商品に連動する。
- 業務上の期限は原則1週間。システムでは登録から14日経過した「仮押さえ」にキャンセル確認を表示し、管理者が手動でキャンセルする。
- 配送情報待ち・本登録はアラート対象外。編集で登録日時は変わらない。登録日時不明の旧データは期限判定しない。
- 期限超過は過去の日程でも一覧に残す。管理表の表示商品・期間に依存しない。
- キャンセルは同じ案件の全商品・全月の元行に適用し、在庫を解放する。元データと監査履歴を残す。コピー元に未完了申請があれば先に取り消す。本登録済み案件はこの操作で取り消せない。
- 配送情報入力済みという独立した登録区分は設けない。本登録を選ぶと従来どおり申請情報の入力・承認・kintone登録へ進む。

2026-11-26時点の既存仮押さえ336案件（337枠）は配送情報待ちに初期設定。配送詳細が揃った未登録申請は0件。登録区分・日程・機器番号・kintoneは変更していない。今後の新規仮押さえは「仮押さえ」で開始する。

書き込みは担当事業を持つ有効な管理者のみ。在庫更新番号を照合して一括保存し、一般ユーザーから保存関数を直接呼ぶことはできない。
