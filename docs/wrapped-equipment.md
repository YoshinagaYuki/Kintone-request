# 特別ラッピング機の分離

スティックキャッチ（大）の物理1号は専用ラッピング品として別商品で管理する。通常版24台は物理番号2〜25（予備23〜25）、ラッピング版1台は1号。合計保有台数は25台のまま。

`item_name_master.unit_number_start` は物理番号の始点。台数の集計値は変更せず、ボード、番号候補、手動指定、切替、自動割当で始点と台数から番号範囲を判定する。未来の在庫数変更でも同じ始点を使う。

`kintone_name` は在庫上の別商品の名称を既存のkintone選択肢へ対応させる任意項目。ラッピング版は申請・在庫上の独立名称を保持し、kintone送信時だけスティックキャッチ（大）へ正規化する。新規登録、コピー、既存案件変更の送信前に適用する。背景スクリーンは通常版と同じ共通在庫を使用する。

移行は在庫更新ロックとバージョン照合の下で一括実行する。通常版の既存1号の予定は、他番号の往復輸送・返却と3日間隔を検証して再割当する。日程・管理番号・申請内容は変えない。変更前のマスタ・在庫・番号割当・編集値と移行計画は作業用の非公開バックアップへ保存する。
