# 自動機器番号の詰め込み優先

単純な小さい番号順から、前後の既存予定に収まりのよい空きへ配置する方法に変更した。既存の番号は動かさず、新規登録や明示的な「自動選択」にのみ適用する。月をまたいでも1つの期間・番号のまま割り当て、切り替えや別レコードは作らない。

候補ごとに、輸送・返却・延長候補・集荷後の丸3日を含めた既存の保護期間の前後を調べ、配置後に残る空きの合計が小さい番号を優先する。前後の予定がない側、または365日以上離れた側は365日として評価し、遠い過去の利用で順位が歪むのを抑える。同点は小さい番号。実際の空き判定にはこの365日の上限を適用せず、期間全体の重複と在庫減少を従来どおり調べる。

申請の複数台は、まず連番で全台入る候補を比較。すでに番号が決まった台がある場合は、その番号へ近づける優先順位を維持する。連番が不可能なら各台を同じ詰め込み基準で選ぶ。予備機は自動で使用しない。手動指定は従来どおり。

これは既存の予定を固定した追加配置の改善であり、全予約を動かす最適化ではない。倉庫休日や輸送・点検の余裕期間自体は短縮しない。

検証：短い空きを埋めて空の個体を残す、複数台の連番候補、輸送余裕と予備・固定番号を維持するケースを追加。全292件の在庫テスト、型チェック、ビルド成功。読み取り専用で実データ80条件を比較し、28条件で従来より小さい残余の候補を選択、52条件は同等。顧客の既存割り当ては変更していない。
